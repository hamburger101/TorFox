TorFox 0.1.0 is the first release of TorFox.

TorFox is an independent browser built on Chromium. It is not Tor Browser and does not offer Tor Browser's protections against fingerprinting.

Browsing
- Tabs, windows, private windows, bookmarks, history and address-bar suggestions from your own bookmarks and history.
- DuckDuckGo is the search engine, also over its onion service in Tor windows.

Tor
- Tor windows send every connection through the official Tor client that comes with TorFox, and wait while Tor is not connected. Onion addresses open only in Tor windows.
- Built-in or custom bridges for networks that block Tor.

Privacy and security
- Trackers and third-party cookies are blocked, pages load over HTTPS first, and pop-ups need a click.
- Camera, microphone and other permissions are blocked unless you choose to be asked.
- Downloads can be turned off, or asked about each time.
- In Tor windows, JavaScript runs without its optimizing compilers, which most attacks on browsers go through (Settings > Privacy & Security > JavaScript optimizer).
- No telemetry, usage statistics or crash reports.

Updates
- TorFox downloads verified updates by itself and shows Relaunch to update when one is ready. On Windows, an update you have not installed yet installs when you close TorFox.
- Every update must be signed with TorFox's release key and match the signed size and SHA-256 before it is installed.

Settings
- Settings > Memory shows how much memory TorFox and each of your tabs use.
